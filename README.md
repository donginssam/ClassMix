# ClassMix

**나이스(NEIS) 반편성 도우미** — 나이스에서 기본 편성한 결과를 화면에서 손으로 조정하고, 나이스에 그대로 올릴 수 있는 XLSX로 내보내는 데스크톱 앱입니다.

- 나이스에서 내려받은 **진급반편성 XLSX**(필수)와 **반편성내역 PDF**(선택, 기준성적 포함)를 불러옵니다.
- 학년 전체 편성표에서 학생을 끌어다 옮기거나 바꾸고, 반별 인원·성적·성비 균형을 보면서 조정합니다.
- 원본 XLSX 양식은 그대로 두고 **진급반코드·진급반번호만 바꿔** 업로드용 파일을 만듭니다.
- Windows는 설치 없이 실행 파일 하나로 사용할 수 있고, macOS도 지원합니다. 인터넷 연결 없이 동작하며 학생 정보를 외부로 보내지 않습니다.

> ClassMix는 자동 배정 도구가 아닙니다. 나이스 기본 편성을 출발점으로 삼아 교사가 직접 다듬는 도구입니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 작업 파일 `.mix` | 반편성 1건(한 학년)이 파일 하나. 모든 변경이 바로 저장되고, 파일만 옮기면 다른 PC에서 이어서 작업할 수 있음 |
| XLSX 가져오기 | 헤더 이름으로 열을 찾고, 전입·전출 행은 건너뜀. 나이스 번호와 결번을 그대로 가져옴 |
| PDF 매핑 | 표를 좌표로 복원해 두 줄로 갈라진 이름도 처리. 매핑 결과를 검토한 뒤 기준성적·성별·생년월일 반영 |
| 편성표 | 행 = 번호, 열 = 반. 드래그로 이동·교환, 검색, 메모, 나이스 기본 편성 대비 변경 표시 |
| 균형 지표 | 반 간 인원 차·평균 성적 차·성비 차를 항상 표시하고 기준을 넘으면 경고 |
| 분리 규칙 | 그룹형·1:N형·쌍둥이·동명이인. 동명이인은 자동 생성, 쌍둥이는 생년월일로 후보 제안 |
| 번호 | 학생이 옮겨간/옮겨온 반만 가나다순 재정렬. 전입생 자리를 위한 빈 번호, 외국 국적 학생의 한글 발음 정렬 |
| 되돌리기 | 단계 제한 없음. 이력이 파일에 남아 앱을 다시 켜도 유지 |
| 내보내기 | 번호 중복 등은 막고 규칙 위반 등은 경고. 저장한 파일을 다시 읽어 값이 맞는지 확인 |

자세한 동작 규칙은 [기능 명세](docs/features.md)를 보세요.

## 사용 방법

1. **새 반편성 만들기**로 `.mix` 파일을 만듭니다(이미 있으면 **파일 열기**나 더블클릭).
2. 나이스에서 기본 편성 후 내려받은 **진급반편성 XLSX**를 가져옵니다.
3. (선택) **반편성내역 PDF**를 가져와 매핑을 확인하고 반영합니다. PDF가 없으면 성적·성별 없이 조정합니다.
4. 편성표에서 학생을 옮기거나 바꾸고, 균형 지표와 분리 규칙 경고를 확인합니다.
5. **내보내기**로 나이스 업로드용 XLSX를 저장합니다.

단축키 목록은 앱에서 `F1` 또는 `?`를 누르면 볼 수 있습니다.

### 설치

[Releases](https://github.com/donginssam/ClassMix/releases)에서 다운로드할 수 있습니다.

- **Windows**: `ClassMix_{버전}_x64.exe`를 원하는 폴더(USB도 가능)에 넣고 실행합니다. 설치 과정이 없고, 설정 파일은 실행 파일 옆에 생성됩니다. `.mix` 파일을 더블클릭해 열려면 앱의 [설정 및 정보]에서 파일 연결을 등록하세요.
  - 코드 서명이 되어 있지 않아 처음 실행할 때 "Windows의 PC 보호" 경고가 뜰 수 있습니다. [추가 정보] → [실행]을 누르세요.
  - Microsoft Edge WebView2 런타임이 필요합니다(Windows 11과 업데이트된 Windows 10에는 기본 설치되어 있음). 없으면 앱이 설치 페이지를 안내합니다.
- **macOS**: `.dmg`를 열어 응용 프로그램 폴더로 옮깁니다.

> 재부팅 시 C 드라이브가 초기화되는 PC에서는 `.mix` 파일을 D 드라이브나 USB에 저장하세요.

## 개발

### 준비

- Node.js 22, pnpm 10
- Rust stable
- [Tauri 2 사전 요구 사항](https://v2.tauri.app/start/prerequisites/)

```bash
pnpm install
```

```bash
pnpm tauri dev
```

### 명령

| 명령 | 내용 |
|---|---|
| `pnpm tauri dev` | 개발 모드로 앱 실행(개발 빌드에는 샘플 적용 버튼이 있음) |
| `pnpm test` | Vitest 단위·골든 테스트 |
| `pnpm test:rust` | Rust 테스트(`cargo test`) |
| `pnpm typecheck` / `pnpm lint` / `pnpm format` | 타입 검사 / ESLint / Prettier |
| `pnpm icons` | `src-tauri/icons/app-icon.svg`에서 아이콘 세트 생성 |
| `pnpm build:win` | Windows 포터블 exe 빌드(`tauri build --no-bundle`) |
| `pnpm tauri build` | 플랫폼별 배포물 빌드(macOS `.dmg` 등) |

GitHub Actions(`.github/workflows/build.yml`)를 통해 Windows·macOS에서 테스트하고 포터블 exe와 유니버설 dmg를 만듭니다. `v*` 태그를 올리면 Release 초안이 생성됩니다.

### 구조

- `src/` — React 화면(`features/`)과 테스트가 함께 있는 순수 로직(`domain/`: PDF 표 복원, 매핑, 번호, 분리 규칙, 통계, 검증)
- `src-tauri/` — Rust: 작업 파일(SQLite), XLSX 읽기·쓰기, 변경 적용과 되돌리기, OS 연동
- `tests/fixtures/` — 더미 샘플 XLSX·PDF와 기대 결과

새 상태 계산은 프런트엔드 순수 함수가, 저장과 파일 입출력은 Rust가 맡습니다. 자세한 내용은 아래 문서를 참고하세요.

- [아키텍처](docs/architecture.md) — 전체 흐름, 역할 분담, `.mix` 파일 형식과 스키마, 빌드·테스트
- [결정 사항](docs/decisions.md) — 설계와 구현 중 내린 결정과 그 이유
- [기능 명세](docs/features.md) — 가져오기·매핑·편성표·분리 규칙·번호·내보내기 동작 규칙

### 개인정보

실제 학생 정보가 들어가는 `*.mix`·`*.xlsx`·`*.pdf`는 `.gitignore`로 커밋하지 않습니다. 테스트에는 `tests/fixtures/`의 더미 데이터만 사용합니다.
