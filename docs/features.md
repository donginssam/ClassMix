## 1. 입력 파일

### 1.1 진급반편성 XLSX (나이스 업로드 양식)

| 열  | 헤더             | 형식        | 비고                                              |
| --- | ---------------- | ----------- | ------------------------------------------------- |
| A   | 학번             | 텍스트(`@`) | **학생 고유키**. 숫자로 읽으면 앞자리 0 손실 경고 |
| B   | 성명             | 일반        | 앞뒤 공백이 있을 수 있음                          |
| C   | 이전주야과정구분 | 텍스트      |                                                   |
| D   | 이전학년         | 일반        | `1학년` / `전입` / `전출`                         |
| E   | 이전반           | 숫자        | 전입·전출이면 빈칸                                |
| F   | 이전번호         | 숫자        | 전입·전출이면 빈칸                                |
| G   | 진급주야과정구분 | 텍스트      |                                                   |
| H   | 진급학년         | 일반        |                                                   |
| I   | 진급반코드       | 숫자        | **편집 대상**                                     |
| J   | 진급반번호       | 숫자        | **편집 대상**                                     |

XLSX에는 성별·생년월일·성적 정보가 없어서 PDF에서만 얻는다.

### 1.2 반편성내역[배정반기준] PDF

- 반당 1쪽, 쪽 하단에 `남(n명) 여(n명) 계:(n)` 요약.
- 열: `학년 | 반 | 번호 | 성명 | 생년월일 | 성별 | 기준성적 | 이전학적(학년·반·번호) | 특이사항`
- 긴 이름이 두 줄로 줄바꿈되어 이름 조각이 행 위·아래로 갈라진다.

### 1.3 데이터 함정 (샘플 분석 결과)

| 문제                                      | 영향                                  | 처리                                                |
| ----------------------------------------- | ------------------------------------- | --------------------------------------------------- |
| 이전반·이전번호 중복(같은 이전학적에 2명) | 이전학적만으로 매핑하면 잘못 연결된다 | 진급반·번호+성명을 1순위 키로, 가져오기 요약에 경고 |
| 이전번호 결번                             | 단순 정보 항목                        | —                                                   |
| 동명이인                                  | 이름 단독 매칭 불가                   | 동명이인 분리 규칙 자동 생성                        |
| 이름 앞뒤 공백                            | XLSX·PDF 이름 불일치                  | 공백 정규화                                         |
| PDF 이름 줄바꿈                           | 정규식 파싱 실패                      | 좌표 기반 병합                                      |
| 전입·전출 행                              | 실제로는 존재할 수 없음               | 두 유형 모두 건너뜀                                 |

## 2. XLSX 가져오기

1. 첫 시트 1행에서 헤더를 **이름으로** 찾는다(열 순서가 바뀌어도 동작). 필수 헤더 누락 시 오류.
2. 학번은 문자열로 읽는다.
3. `이전학년`이 `전입`/`전출`이거나 이전반·이전번호가 빈 행은 건너뛴다.
4. 진급반코드·번호를 `orig_*`, `cur_*`에 저장. 대상 학생 중 하나라도 비어 있으면 "나이스에서 기본 편성 후 내려받은 파일이 아닙니다"로 중단.
5. 반 수 = 진급반코드 최댓값. 나이스 번호의 결번은 빈 번호(`origin='import'`)로 가져온다.
6. 원본을 `source_file`에 보관(내보내기 템플릿).
7. 동명이인 그룹마다 `same_name` 규칙 자동 생성.
8. 가져오기 요약: 대상 인원, 반별 인원, 건너뛴 행, 데이터 경고(이전학적 중복 등), 한글 표기 입력이 필요한 로마자 성명 학생 수 → 대상이 있으면 **한글 표기 입력 단계**(건너뛰기 가능).

## 3. PDF 가져오기와 매핑

### 3.1 표 추출 (`pdfExtract.ts`, `pdfTable.ts`)

1. `pdfjs-dist`로 쪽별 텍스트 아이템(문자열 + x, y) 수집.
2. 헤더 행 x 좌표로 열 경계 산출.
3. `n학년` 아이템의 y를 행 앵커로 삼고, 앵커 사이 성명 열의 위·아래 조각(줄바꿈된 이름)을 앵커 행에 병합.
4. 하단 요약으로 쪽별 행 수 검증(불일치 시 경고).
5. 이전학적이 `전입`/`전출`인 행은 행 수 검증에만 세고 매핑에서 제외.

### 3.2 매핑 (`matching.ts`)

정규화: 이름은 공백·줄바꿈을 한 칸으로 축약 후 trim, 숫자는 숫자 문자만 추출.

| 순위 | 키                          | 조건                         |
| ---- | --------------------------- | ---------------------------- |
| 1    | (진급반, 진급반번호) + 성명 | 기본                         |
| 2    | (이전반, 이전번호) + 성명   | 키가 XLSX 안에서 유일할 때만 |
| 3    | 성명 단독                   | 유일할 때만, "확인 필요"     |
| —    | 그 외                       | 미매칭 → 수동 연결           |

매핑 검토 화면에서 자동 확정 / 확인 필요 / 미매칭 / PDF에만 있음 / XLSX에만 있음으로 나눠 보여 주고, [반영]해야 `base_score`·`gender`·`birth_date`·`match_method`를 기록한다. 충돌은 반영 불가.

## 4. 반편성 보드

- **편성표**: 행 = 번호, 열 = 반. 번호 축·반 머리글 고정. 셀에 이동한 학생, 분리 위반, 쌍둥이·동명이인, 빈 번호 표시. 학생별 나이스 원래 반 툴팁.
- **반 머리글**: 인원, 성별 막대, 학년 평균 대비 편차, 분리 위반 시 빨간 띠.
- **조작**: 선택 후 바꾸기·다른 반 이동, 드래그 앤 드롭(반 위로 → 이동, 학생 위로 → 교환).
- **되돌리기/다시 실행**, 변경 이력 패널(되돌린 항목 포함, 바뀐 학생 하이라이트). 이력은 파일에 영구 저장.
- 학생 검색(성명·한글 표기) 후 해당 셀로 이동, 표시 옵션, 메모 편집.
- "나이스 기본 편성으로 되돌리기"(전체 초기화, 확인 후, 되돌리기 가능).
- macOS에서는 메뉴의 되돌리기/다시 실행 항목을 직접 만들어 Cmd+Z가 보드에 전달되게 했다.

### 4.1 균형 지표와 통계 (`stats.ts`)

| 지표                              | 경고 기준 |
| --------------------------------- | --------- |
| 반 간 인원 차(최대−최소)          | 2명 이상  |
| 반 평균 성적 차(학년 평균 대비 %) | 2% 이상   |
| 성비 차(반별 \|남−여\|의 최댓값)  | 4명 이상  |

통계표(선택): 반별 인원·남/여·이전 n반 출신 분포(히트맵)·성적 평균/표준편차/최고/최저·마지막 번호·빈 번호 수. PDF가 없으면 성적·성별 항목을 숨긴다. 인원에는 빈 번호를 세지 않는다.

## 5. 분리 규칙

| 종류          | 의미                                  | 만드는 방법                       |
| ------------- | ------------------------------------- | --------------------------------- |
| 그룹형(A:B:C) | 모두 서로 다른 반                     | 교사가 직접                       |
| 1:N형(A:BCD)  | A와 B·C·D는 다른 반, B·C·D끼리는 무관 | 교사가 직접                       |
| 쌍둥이        | 형제 모두 서로 다른 반                | 후보 검토 후 확정, 또는 직접 등록 |
| 동명이인      | 같은 이름끼리 서로 다른 반            | XLSX 가져올 때 자동               |

- 규칙마다 켜기/끄기와 사유. 꺼진 규칙은 검사하지 않고 흐리게 남는다.
- 학생 선택은 자동완성(성명·한글 표기). 동명이인은 `(이전 반-번호, 성별)`로 구분. 학번은 표시·검색에 쓰지 않는다.
- 드래그 중 위반이 생기면 대상 반을 빨간색으로 미리 표시하고, 놓은 뒤 되돌리기 버튼이 있는 토스트로 알린다(막지는 않음).

### 5.1 동명이인

공백을 모두 지우고 대문자로 바꾼 성명이 같은 학생들(`names.rs` `same_name_key`). 그룹마다 `same_name` 규칙 1개.

### 5.2 쌍둥이 후보 (`siblings.ts`)

PDF를 넣었을 때만 만든다. 같은 생년월일끼리 묶은 뒤:

- **유력**: 생년월일 + 성 같음. 한글은 복성(남궁·제갈·선우·황보·독고·사공·서문 등)을 먼저 확인한 뒤 첫 글자. 로마자는 성-이름 순이 원칙이지만 등록 순서가 일정하지 않아, 공백으로 나눈 단어 중 하나라도 같으면 같은 성.
- **가능**: 생년월일만 같음. 기본 체크 해제.
- 세쌍둥이 이상은 한 그룹으로.
- PDF 반영 직후 검토 화면에서 [쌍둥이로 등록] / [아님]. [아님]은 `twin_candidate_dismissed`에 남겨 다시 묻지 않는다.

## 6. 번호 (`numbering.ts`)

### 6.1 재정렬

1. 반 학생을 정렬 키(`sort_name`이 있으면 그것, 없으면 성명)로 가나다순, 같으면 학번순.
2. 빈 번호의 위치 키 = 예정 이름의 정렬 키, 없으면 만들 때 바로 앞 학생의 정렬 키(맨 앞이면 빈 문자열).
3. 학생과 빈 번호를 키 순서로 합친다. 키가 같으면 학생이 먼저(빈 번호는 기준 학생 바로 뒤).
4. 1번부터 차례로 번호. 빈 번호도 번호 하나를 차지한다.

이동·바꾸기가 일어난 반은 자동으로 재정렬되고 `class_state`가 `sorted`가 된다. 손대지 않은 반은 `original`(나이스 번호 그대로).

### 6.2 번호 직접 수정과 빈 번호

```
수정 전  13 김나래  14 김다온  15 김라희  16 김마루 …  29 홍하늘
         ↓ 김라희의 번호를 15 → 16으로 수정
수정 후  13 김나래  14 김다온  15 (빈 번호)  16 김라희  17 김마루 …  30 홍하늘
```

- 번호를 늘리면 그 학생 앞에 빈 번호가 생기고 그 학생과 뒤 학생이 모두 밀린다.
- 번호를 줄이면 바로 앞의 빈 번호를 지우고 당긴다. 앞 학생 번호와 겹치면 거절.
- 학생 순서는 바뀌지 않는다. 적용 전 영향 범위 미리보기를 보여 준다.
- 오른쪽 클릭 [앞에 빈 번호 넣기] / 빈 번호 [지우기]·[예정 이름 편집].
- 전입 예정 이름을 적으면 그 이름의 가나다 위치에 놓인다.
- 마지막 학생 뒤에는 빈 번호를 만들 수 없다.
- 각 동작은 되돌리기 1단위(`set_number`, `gap_add`, `gap_remove`, `gap_edit`).

### 6.3 로마자 성명의 한글 표기

- 배경: 학적업무요령에 따라 외국인 학생의 성명은 여권(외국인등록증, 외국인등록 사실증명)을 기준으로 한다. 등록증에 로마자와 한글 표기가 함께 있으면 보호자가 둘 중 하나를 고른다. 한글 표기를 고른 학생은 그대로 가나다순에 들어가지만, 로마자 표기를 고른 학생은 나이스 성명이 로마자라 가나다 자리를 정할 수 없으므로 한글 표기로 옮겨 적어야 한다.
- 대상: 성명에 로마자가 들어 있는 학생. 한글 성명 학생에게는 입력칸을 보이지 않는다.
- 입력: 가져오기 후 한글 표기 입력 단계, 또는 학생 메뉴. 「외국인의 성명 표기에 관한 표준」 제6조제2항에 따라 로마자 성명을 기준으로 원래 성명의 **원지음**(原地音)을 따라 외래어 표기법에 맞춰 적고, 순서는 **성-이름**이다(예: `PHAM HANNI` → `팜하니`). 한글만 받고 공백은 지운다. 비우면 표기 없음.
- `sorted` 반은 입력 즉시 재정렬(`set_reading`), `original` 반은 번호를 건드리지 않고 안내만.
- 표시: 성명 옆에 한글 표기(`PHAM HANNI 팜하니`), 없으면 `한글 미입력`.
- 한글 표기는 번호 정렬과 검색에만 쓴다. 내보내는 성명, PDF 매핑, 동명이인 비교는 원래 로마자 성명 기준 그대로.

## 7. 내보내기

1. 검증(`validate.ts`)
   - ❌ 차단: 같은 반 번호 중복(빈 번호 포함), 범위 밖 반, 잘못된 번호
   - ⚠️ 경고: 분리 규칙 위반, 반 간 인원 차, PDF 매핑 미완료, 재정렬된 반의 한글 표기 미입력 로마자 성명
   - ℹ️ 안내: 빈 번호 목록(업로드 파일에서는 결번), 나이스 기본 편성 대비 반이 바뀐/번호만 바뀐 학생 수
2. Rust가 차단 조건을 다시 확인한 뒤 저장된 원본 XLSX를 열어 진급반코드·진급반번호 셀만 숫자 값으로 기록, 전입·전출 행 삭제.
3. 임시 파일에 쓰고 다시 읽어 행 수·학번·값을 확인한 뒤 대상 파일로 교체.
4. 기본 파일명 `{작업 파일명}_나이스업로드_{YYYYMMDD-HHmm}.xlsx`, 기본 위치는 `.mix`와 같은 폴더.

## 8. 비밀번호 보호(암호화)

작업 파일에 비밀번호를 걸면 학생을 식별할 수 있는 자료(학번·성명·생년월일·기준성적·메모·원본 XLSX/PDF 등)가 암호화되어 저장된다. 기본은 암호화하지 않음. 방식과 대상 칸은 [아키텍처 — 암호화](architecture.md#암호화) 참고.

- **설정**: 파일 메뉴 → 비밀번호 설정. 비밀번호를 두 번 입력(8자 이상, 공백만은 불가). 모든 자료를 한꺼번에 암호화한다.
- **열기**: 암호가 걸린 파일을 열면 잠금 해제 화면이 나온다. 비밀번호가 맞아야 편성표·가져오기·내보내기 등 모든 작업을 할 수 있다.
- **변경**: 현재 비밀번호를 확인한 뒤 새 비밀번호로 모든 자료를 다시 암호화한다. 새 비밀번호는 현재와 달라야 한다.
- **해제**: 현재 비밀번호를 확인한 뒤 암호화하지 않은 상태로 되돌린다. 이후에는 비밀번호 없이 열린다.
- **다른 이름으로 저장·사본**: 같은 비밀번호로 암호화된 채 저장된다.
- **주의**: 비밀번호를 잊으면 파일을 다시 열 수 없다. 내보낸 나이스 업로드용 XLSX는 암호화되지 않는다.

## 9. 시작 화면·파일·단축키

- 시작 화면: [새 반편성 만들기] [파일 열기] + 최근 파일(없어진 파일은 흐리게). `.mix`를 끌어다 놓아도 열린다. 파일 연결 후 exe가 옮겨졌으면 재등록 안내.
- 파일 메뉴: 다른 이름으로 저장, 사본 저장, PDF 추가/교체, 비밀번호 설정·변경·해제, 닫기.
- 단축키(Ctrl / macOS는 ⌘): N 새로 만들기, O 열기, Shift+S 다른 이름으로 저장, E 내보내기, Z 되돌리기, 다시 실행(Windows Ctrl+Y 또는 Ctrl+Shift+Z, macOS ⌘+Shift+Z), F 검색(Enter: 다음 결과), Esc 선택 해제, F1 또는 `?` 단축키 목록.
- 오류 처리: `ErrorBoundary`(흰 화면 대신 다시 불러오기), 처리 안 된 비동기 오류 토스트, 파일 사용 중·권한·USB 빠짐 등 IO 오류를 이해하기 쉬운 문구로 안내한다.
- 개발 빌드에서만 "샘플 적용" 버튼.
